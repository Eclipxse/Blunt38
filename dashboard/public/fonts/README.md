# blunt38 Studio fonts

These font files are distributed by the Google Fonts project and are bundled so
the Studio preview and the Discord card renderer use the same typography.

- Source: https://github.com/google/fonts
- OFL families: see `OFL-1.1.txt`
- Apache families: see `Apache-2.0.txt`

The files are kept in their original TrueType format. The application maps each
filename to its family name in `dashboard/src/lib/visual-document.ts` and
`src/services/welcome-card.ts`.
